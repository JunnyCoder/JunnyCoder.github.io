# 이력서 파일 관리

PDF Maker에서 문서 작성 후 **작업 파일 저장**으로 내려받은 파일을 다음 이름으로 추가합니다.

| 언어 | 파일명 |
| --- | --- |
| 한국어 | `resume_ko.jpdf.json` |
| 영어 | `resume_en.jpdf.json` |

홈페이지 이력서 모달은 이 두 파일만 읽습니다. 파일이 없는 언어는 “이력서를 준비 중입니다”를 표시하고 인쇄를 비활성화합니다. 기존 `resume_ko.json` / `resume_en.json`은 변경하지 않았으며 새 뷰어에서는 사용하지 않습니다.

PDF Maker와 뷰어는 같은 A4 렌더러·설정·테마를 사용합니다. 뷰어는 브라우저 초안, 편집 이력, IndexedDB에 기록하지 않습니다. 업로드한 본문 이미지는 프로젝트 자산으로 포함되며, 표지 파일 이미지는 기존과 같이 data URL로 포함됩니다. URL로 넣은 이미지는 네트워크 접근이 필요합니다.

문서 내용은 이 리팩터링에서 생성하거나 변환하지 않았습니다. 실제 파일을 추가한 뒤 한국어·영어 전환과 인쇄 결과를 확인하세요.
